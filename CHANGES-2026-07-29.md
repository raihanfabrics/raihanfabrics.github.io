# Changes — 2026-07-29

## 1. Fixed the stock-sync bug (manual edit → gets overwritten by next purchase)

**Root cause:** `fabrics.stock_meters` is kept in sync by a DB trigger that
recomputes it as `sum(stock_batches.meters_remaining)` every time a batch
changes (see `migration_2026-07-26-stock-sync.sql`). Editing stock manually
in Inventory wrote the number straight onto `fabrics.stock_meters` — but
never touched `stock_batches`. So the next time *any* batch changed (a
Market Mode purchase, a sale, anything), the trigger recomputed from the
batches — which still summed to the old number — and silently threw the
manual edit away, then added the new purchase on top of the stale total.
That's exactly the 50 → edit to 35 → +20 purchase → shows 70 (should be 55)
behavior you described.

**Fix:** manual stock edits (and a new fabric's opening stock) now go
through a proper batch-level adjustment (`adjustFabricStock` in
`supabaseApi.js`, `adjustFabricStockLocal` in `localStore.js` for the
offline fallback) instead of writing `stock_meters` directly:
- Increasing stock opens a new zero-cost "adjustment" batch for the
  difference (keeps FIFO cost-of-goods on your real purchases honest —
  doesn't invent a purchase price for a manual count fix).
- Decreasing stock draws the difference down from existing batches
  oldest-first, same order sales already use.
- Every adjustment is logged to `stock_movements` (`movement_type:
  'adjustment'`) for the audit trail.

No SQL migration needed — the `adjustment` movement type and the batch
columns used were already in the schema.

## 2. Archived fabrics moved to an owner-only section

Archived fabrics no longer show (even greyed-out) in the main Inventory
list. If you're signed in as the owner, a collapsed "Archived fabrics (N)"
section appears below the main table — tap "View archived" to see them
and Restore any of them. Staff accounts don't see this section or an
archived count at all.

## 3. "Add to Purchase List" button on inventory rows

Every row in Inventory now has a cart button that adds that fabric
straight to the Purchase List (same mechanism as "add a fabric manually"
on that screen — persists across refresh, and feeds a Market Mode trip
seeded from the Purchase List).

## 4. Edit button for planned purchase quantity

Purchase List rows now have a pencil icon next to the suggested quantity —
tap it to type in exactly how much you plan to buy instead of the
auto-suggested amount. The edit is remembered (shown as "planned"), the
estimated budget recalculates from it, and it's what actually gets loaded
into a Market Mode trip if you seed one from the Purchase List afterward.

## 5. Enlarged the storefront/header logo

Bumped the header brand mark from 20px to 38px.

## 6. All-time purchased total per supplier

Suppliers table now shows a "Total Purchased (all-time)" column — total
meters and total spend across every batch ever bought from that supplier
(lifetime figure, doesn't drop as stock sells through, unlike current
remaining stock).

## 7. Suggested suppliers section on a Market Mode trip

Active trips now show a "Suggested suppliers for this trip" section above
the shopping list, grouping suppliers by purchase history for the items
that were already on the trip when it started (i.e. loaded from the
Purchase List) — not items you find and add on the spot mid-trip, since
those don't have a "planned supplier" to suggest yet. Each card shows the
supplier's name and which of your planned fabrics they've sold before, at
what price.
